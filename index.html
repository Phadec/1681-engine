1681 Engine examples

  • walk-room: one scene, three components, three systems, pixel effects.
  • multiplayer: open it in two tabs after npm run example:server: prediction, reconciliation and interpolation through an authoritative server.
  • night-garden: the core with smooth vector art, no pixel module: a rigged character animated by blended poses, a lantern and fireflies in the dark, a soft camera.
  • pixel-dungeon: the pixel module: dithered torchlight, a carried light, slimes that evaporate into their own pixels.
  • ecs-stress: tens of thousands of bodies moved by typed-array components, with the frame rate and step time.
  • platformer: a small side-scroller on the newer modules together: rigid-body physics from a tile grid (crates, a moving platform, one-way planks), particles, a canvas HUD and pause menu with gamepad focus, a versioned save, dithered transitions, two languages, a rebindable jump key, F3 for the physics overlay.
  • physics-toys: bodies that turn (boxes, balls, polygons, a spinning bar) and full-screen effects: bloom, vignette, chromatic aberration, CRT, pixelate, a shockwave and a flash.
  • lobby: open it after npm run example:lobby: rooms with a host, codes, ready flags and chat, a matchmaking queue by rating and a ready check, on the React kit; five bots keep the queue busy.
  • aseprite: an Aseprite sheet (tags, slices, cel data) read into clips, driven by an animation state machine (idle, run, jump, fall, land) whose frame markers fire footsteps.
  • top-down: a Tiled map, asset loading, an animated hero, input actions (keyboard, gamepad, touch), camera follow.
  • dialogue: a playground for dialogue scripts: edit the JSON, see what the checker finds as you type, play it through with its variables in view.
  • ldtk: an LDtk project with separate level files, IntGrid collision, entity fields, click-to-edit walls autotiled with blob rules.
